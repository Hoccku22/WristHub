# Участие

Для ошибки создай issue с моделью часов и телефона, версиями ОС, версией приложения
и последовательностью действий. Снимок экрана помогает понять проблему; личные
документы и их содержимое публиковать не нужно.

Перед изменением кода прочитай [BUILD.md](docs/BUILD.md) и
[описание Bluetooth-транспорта](docs/TRANSPORT.md). Приложение должно сохранять
Bluetooth-only обмен: Data Layer с возможным Wi-Fi fallback не подходит.

Для проверки изменений:

```bash
./gradlew :mobile:assembleDebug :wear:assembleDebug :shared:testDebugUnitTest :mobile:lintDebug :wear:lintDebug
```

Если реальных часов нет, укажи это в описании изменений. Не выдавай JVM-тесты
или эмулятор за подтверждение Bluetooth-связи на физическом устройстве.

Лицензия на переиспользование исходников пока не выбрана; существенные изменения
и условия их включения лучше предварительно обсудить с владельцем репозитория.
