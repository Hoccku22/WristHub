# Установка WristReader

Нужны два разных APK из [последнего релиза](https://github.com/Hoccku22/WristReader/releases/latest):

- `WristReader-phone.apk` — телефон, Android 8.0+.
- `WristReader-watch.apk` — часы, Wear OS на Android 11+.

## Телефон

Скачай `WristReader-phone.apk`, открой файл и разреши установку этому источнику,
если Android запросит. После установки открой WristReader и разреши Bluetooth.

## Часы с помощью телефона

Этот способ позволяет обойтись без компьютера и командной строки, но использует
ADB внутри установщика. Для полного восстановления приложения на новых или
сброшенных часах понадобится снова включить беспроводную отладку.

1. Скачай `WristReader-watch.apk` в папку загрузок телефона.
2. Установи [Wear Installer 2 из Google Play](https://play.google.com/store/apps/details?id=org.freepoc.wearinstaller2) на телефон.
3. Подключи телефон и часы к одной доступной им Wi-Fi сети.
4. На часах открой настройки разработчика и включи ADB / беспроводную отладку.
   Чтобы открыть настройки разработчика, несколько раз нажми номер сборки в
   «Система → Об устройстве → Версии». Названия разделов зависят от прошивки.
5. В Wear Installer 2 введи IP часов. Выбери **Pair with watch**.
6. На часах выбери «Подключить новое устройство» и введи в установщик показанные
   код сопряжения и порт сопряжения.
7. После сопряжения укажи порт подключения с главного экрана беспроводной отладки.
   Он отличается от порта сопряжения.
8. В Wear Installer 2 выбери **Custom APK**, укажи `WristReader-watch.apk` и нажми **Install**.
9. После установки отключи беспроводную отладку. Для передачи PDF и фото Wi-Fi не нужен.

Подробности и решение проблем: [инструкция автора Wear Installer 2](https://freepoc.org/wear-installer-2-help-page/).
Работа именно этого способа с WristReader пока не проверялась отдельно; APK на
Xiaomi Watch 2 Pro устанавливался через обычный ADB с компьютера.

## Часы с компьютера

Установи Android Platform Tools и выполни:

```bash
adb pair WATCH_IP:PAIRING_PORT
adb connect WATCH_IP:DEBUG_PORT
adb -s WATCH_IP:DEBUG_PORT install -r WristReader-watch.apk
adb -s WATCH_IP:DEBUG_PORT shell am start -n dev.wristreader.wear/.MainActivity
```

Код сопряжения вводится по запросу. Вместо примеров подставь адреса с часов.
После завершения беспроводную отладку можно выключить.

## Первая отправка

1. Сопряги часы с телефоном обычным способом через приложение-компаньон Xiaomi.
2. Открой WristReader на часах. После выдачи Bluetooth-разрешения приём включится сам.
3. На телефоне выбери часы из списка сопряжённых устройств.
4. Выбери PDF, JPEG, PNG или WebP. Дождись подготовки, затем нажми «Отправить».
5. Не сворачивай приложение часов до «Доставлен ✓» на телефоне.

Приём можно выключить кнопкой; при сворачивании он также прекращается. При
следующем открытии часов включится снова. Настройки чтения находятся под ⚙ в меню.

## Обновление и восстановление

APK из этого репозитория подписаны debug-ключом. Текущий релиз соответствует
сборкам, установленным при разработке. `adb install -r` обновляет совместимую
подпись поверх старой версии; установщик телефона обычно также предлагает обновление.

Если Android сообщает о несовместимой подписи, не удаляй приложение поспешно:
сначала сохрани оригиналы документов. Удаление WristReader удаляет его приватную
библиотеку; после установки на новые часы документы нужно передать заново.

Сохрани APK и архив исходников дополнительно в личном резервном хранилище.
Контрольные суммы опубликованы в `SHA256SUMS.txt` каждого релиза.
